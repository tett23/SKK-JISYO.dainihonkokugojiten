## 評価の方法

今回は、新たに紙面の画像と照合する抜き取りは行わなかった（作業のトークンの節約のため）。
代わりに、これまでの評価で紙面と照合して判定した 27,370 件（`docs/accuracy/*/*.tsv`）のうち、方策で検証済みに移る見出しと重なるものの正誤を数えた。
判定済みの見出しは、過去の抜き取り（辞書全体からの無作為抽出と、未検証の層ごとの抜き取り）に由来する。方策の対象から無作為に選んだものではないので、正解率は目安である。
基準は、L 除外辞書の正解率 99%（v1.0.17 は 99.95%）。

## 案ごとの詳細

### A. 二つのエンジンが一致した「理由なし」（`PROMOTE_AGREE=1` / `=2`）

理由なしの未検証 19,857 件のうち、ndlocr-lite（紙面全体）と NDL 側 OCR の読み・表記が一致したのは 7,962 件だった。
すべて移すと（A）、過去の判定との重なりは 141 / 163（86.5%）で、基準に遠い。
層（表記の字数、品詞、五十音順の外れ）に分けても、最も良い層（2 字の名詞、五十音順の外れなし。2,143 件）で 49 / 55（89%）だった。

| 層（字数・品詞・五十音順） |  件数 | 正しい / 判定済み |
| -------------------------- | ----: | ----------------: |
| 3 字以上・名詞・外れなし   | 3,011 |           48 / 56 |
| 2 字・名詞・外れなし       | 2,143 |           49 / 55 |
| 1 字・動詞・外れなし       |   474 |             7 / 7 |
| 2 字・動詞・外れなし       |   467 |             8 / 9 |
| 3 字以上・名詞・外れあり   |   419 |             8 / 9 |
| 2 字・名詞・外れあり       |   396 |            7 / 10 |
| 1 字・名詞・外れなし       |   335 |             6 / 7 |
| そのほか                   |   717 |            8 / 10 |

誤り 22 件の多くは、二つのエンジンが同じように取り違えやすいかなを誤読したもの（送金 おくり-さん、紙面は おくり-きん。紅錦 こう-さん、紙面は こう-きん。周防梅 すはう-らめ、紙面は すはう-うめ。き/さ、う/ら の取り違え）だった。
エンジンが違っても、字形の取り違えは同じように起きる。

A2 では、読みの 1 字を取り違えやすいかなに置き換えた読みが、L・JMdict に載るか音訓に対応付くものを除いた。
送金・紅錦・周防梅 のような誤りは除けたが、6,308 件が残り、重なりは 109 / 120（90.8%）にとどまった。
残った誤りは、表記の誤読（衣腰、鐵色箭、春穗刈 を 舂穗刈 の誤読）、清濁（忌忌氣 いまいまし-け、紙面は げ）、字の取り違え（醜國 しさ-ぐに、紙面は しこ-ぐに）。

検証済みの辞書には入れられない。未検証辞書より誤りが少ない「中間の辞書」として分けるなら、A2（約 91%）は候補になる。

### B. 字の読みの学習を広げる（`LEARN_MIN=2`、`LEARN_WIKT=1`）

字の読みの学習（`learnReadings`）は、L・JMdict の語から、Unihan に無い字の読みを取り出す。根拠の語が 3 語以上ある読みだけを採っている。

- B1（根拠を 2 語に下げる）: 395 件が新たに検証済みになるが、33 件が検証済みから外れる。読みの候補が増えて、ほかの規則（清濁の判定など）の判断が変わるため。重なりは 17 / 19 で、重曹 ぢゅう-そ（じゅうそう）、文箱 ふん-ばこ の誤りが入る
- B2（Wiktionary の語も根拠にする）: 84 件が新たに検証済み、4 件が外れる。重なりは 14 / 14
- B3（両方）: 483 件、外れる 34 件、重なり 19 / 21

B2 は採用の候補。外れる 4 件と新たな 84 件を、抜き取りで紙面と照合してから既定にするのがよい。

### C. どれかの系統の表記が L に載れば採る

表記の一致不足（`align-single-notation`、3,549 件）のうち、元の OCR・NDL 側 OCR・読み直しのどれかの表記が、その見出しの読みで L に載るのは 12 件だけだった。
そのうち 危宿 きしゅく → 寄宿、雉 ち → 蜘 は明らかな誤り。照合（`resolve`）がすでに NDL 側 OCR の表記を試しているので、残っているものは少ない。規則にしない。

### D. 別の見出しの語釈に「読み（表記）」が出るものを採る

底本の語釈は、ほかの語を「よみ（表記）」の形で参照する（「こえ(肥)の訛り」）。全 4 巻の語釈から 7,448 組を集めた。
未検証の見出しのうち、自分以外の見出しの語釈にその読み（歴史的仮名遣い）と表記の組が出るものは 497 件。

| 未検証の理由            | 件数 |
| ----------------------- | ---: |
| （なし）                |  426 |
| `voicing-ambiguous`     |   27 |
| `align-single-notation` |   25 |
| `align-single-reading`  |   10 |
| `align-rendaku`         |    7 |
| そのほか                |    2 |

過去の判定との重なりは 15 / 16（誤りは 左輔 さふ、紙面は さ-ほ）。
紙面上の別の箇所の OCR で裏付けられるので、二つのエンジンの一致（案 A）より独立性が高い。ただし同じ ndlocr-lite の読みなので、取り違えやすいかなの誤読（き/さ）が両方の箇所で起きる可能性は残る。
件数は小さいが、採用の候補。規則として組み込み、抜き取りで紙面と照合してから既定にするのがよい（今回は数えただけで、cleanse には組み込んでいない）。

### E. 系統ごとの濁点の当たりやすさで重み付けする

辞書で清濁が決まった検証済みの見出し 472 件を正解として、系統の読みが濁点で割れた位置での各系統の正解率を求めた。

| 系統                    | 清音を読んだとき | 濁音を読んだとき | 半濁音を読んだとき |
| ----------------------- | ---------------: | ---------------: | -----------------: |
| ndlocr-lite（紙面全体） |  21%（42 / 201） |   9%（22 / 257） |     14%（11 / 77） |
| NDL 側 OCR              |  60%（81 / 134） |  72%（92 / 128） |     87%（33 / 38） |
| 見出しの読み直し        | 78%（157 / 201） | 59%（130 / 221） |     36%（25 / 70） |

割れたときの紙面全体の OCR は、ほとんど当たらない。ただし、この学習データは「辞書で決まった」見出しに偏っている（紙面全体の OCR の読みが辞書に合わなかったから割れとして残った、という選択の偏りがある）。

この重みで清濁の割れた層（`voicing-ambiguous`、3,304 件）を多数決すると、1,551 件の読みが変わる。
判定済みのうち、誤り 25 件のうち 21 件を変える（多くは紙面の読みに直る。殘盃 ざんぱい、前議 ぜんぎ、賊魁 ぞくくわい、民部官 みんぶくわん）が、正しい 126 件のうち 50 件を崩す。差し引きで悪くなるので採らない。
E2（NDL 側 OCR と読み直しが同じ濁点で、紙面全体と違うときだけ直す）は、変わるのが 27 件で、誤り 15 件のうち 1 件しか変えない。効果が小さい。

学習データの偏りを除くには、清濁の割れた層から無作為に抜き取って判定したもの（tier-voicing、96 件）を学習に使う必要があるが、件数が少ない。

### F. 文語の動詞の活用の変換を足す

理由なしの動詞は 2,218 件。30 件を見ると、読みや表記の誤読（搔覺 かささます、隣 ひすろぐ、返申 かへさひまうす）と、表記が熟字訓で字ごとに対応付かないもの（呻吟臥 よひふす、罷出 まかんでる）が大半だった。
活用の変換（下二段 → 下一段、上二段 → 上一段、サ変）はすでにあり、変換が足りずに未検証になったものは見当たらなかった。規則にしない。

### G. 人の確認の仕組み

実装していない。規則で正誤を決められない層（理由なし、清濁の割れ）を減らす手段として、案のまま残す。

## 考察

- **二つのエンジンの一致は、検証済みの根拠としては弱い。** 字形の取り違え（き/さ、う/ら）は、エンジンが違っても同じように起きる。理由なしの層では、一致したものでも 1 割前後が誤りだった。検証済みに移すには、辞書や音訓など、OCR とは独立した根拠が要る。
- **独立した根拠を増やす方策（B2、D）は、件数は小さいが精度が高い。** Wiktionary を字の読みの学習に使う（84 件）と、語釈の参照で裏付ける（497 件）は、過去の判定との重なりで誤りが少なかった。いずれも抜き取りで確かめてから既定にするのがよい。
- **根拠の閾値を下げる方策（B1）は、ほかの規則に波及する。** 字の読みが増えると、清濁の判定や連濁の検査の判断が変わり、正しい見出しが検証済みから外れた。
- **清濁は、系統の重み付けだけでは決められない。** 学習データが辞書で決まった見出しに偏り、割れた層の実態と合わない。清濁の割れた層は、紙面の画像から濁点を直接判定する仕組み（発音の注記の判定と同じ、画像の特徴による判定）か、人の確認が要る。
- **残りの多くは規則では移せない。** 未検証の 2/3 を占める理由なしの層は、OCR の誤読を含む割合が高い。未検証辞書をさらに二つに分け（A2 で約 91% の層と、それ以外）、利用者が選べるようにするのが現実的な次の一手になる。

## 次の手順の案

1. B2（`LEARN_WIKT=1`）と D を、それぞれ新たに検証済みになる見出しから 100 件抜き取って紙面と照合し、基準を満たせば既定にする
2. A2 の層を「準検証済み」の辞書として分けるかを決める（辞書を一つ増やすと、利用者が選ぶ手間が増える）
3. 清濁の割れた層は、紙面の画像から濁点を判定する仕組みを試す

## 再現

```bash
git checkout feature/unverified-reduction
deno task cleanse                                   # 基準
PROMOTE_AGREE=1 deno task cleanse                   # 案 A
PROMOTE_AGREE=2 deno task cleanse                   # 案 A2
LEARN_MIN=2 deno task cleanse                       # 案 B1
LEARN_WIKT=1 deno task cleanse                      # 案 B2
LEARN_MIN=2 LEARN_WIKT=1 deno task cleanse          # 案 B3
```

案 C・D・E・F の件数は、cleanse の出力（`data/cleanse/*.json`）と抽出結果、読み直しの結果（`data/recheck/*.json`）をスクリプトで集計したもの（cleanse には組み込んでいない）。
